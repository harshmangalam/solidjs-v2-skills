# SolidJS Skills

Agent skills that help coding agents write correct, idiomatic **SolidJS v2** code.

> These skills cover **SolidJS v2** only. SolidJS 1.x is not covered.

## Install

```bash
npx skills add harshmangalam/solidjs-skills
```

This copies the skills into your project so your coding agent (Claude Code, Codex, Cursor, Copilot, and others) can use them.
